# zmk-config-go60

This repo serves as a "companion-repo" to [aekeynox](https://github.com/OneDeadKey/zmk-config-aekeynox)
to declare the "hardware" config of Go60 MoErgo keyboard.  

The content of this repo is essentially a small extract of the official [MoErgo fork of ZMK](https://github.com/moergo-sc/zmk)
for the specific `zephir-4-1` branch, structured as a "ZMK user config".
